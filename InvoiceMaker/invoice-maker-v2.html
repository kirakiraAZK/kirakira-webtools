EmailJS Config

Ikuti langkah di bawah satu per satu — isi kolom yang muncul setelah tiap langkah.

1. Daftar di emailjs.com
Buat akun gratis di EmailJS pakai email toko Anda. Buka EmailJS →
📸 Screenshot: Halaman registrasi EmailJS (emailjs.com/sign-up)
2. Tambah Email Service
Menu Email Services → Add New Service → pilih Gmail/Outlook → izinkan akses. Salin Service ID yang muncul, tempel di bawah ini.
📸 Screenshot: Halaman Email Services → pilih provider → tampil Service ID
3. Buat Template Invoice
Menu Email Templates → Create New Template → di kolom Content pilih mode HTML, lalu paste kode di bawah ini.

PENTING: Di panel kanan, isi kolom To Email dengan {{email}} agar email tidak gagal terkirim.
📸 Screenshot: Panel kanan template editor — isi kolom "To Email" dengan {{email}}
{{html_body}}
4. Buat Template Paid
Buat template kedua khusus konfirmasi pembayaran. Paste kode HTML di bawah ke kolom Content (mode HTML).

PENTING: Pastikan juga kolom To Email diisi dengan {{email}}.
📸 Screenshot: Template editor untuk konfirmasi pembayaran
{{html_body_paid}}
5. Ambil Public Key
Menu Account → General, salin Public Key Anda.
📸 Screenshot: Halaman Account → General → Public Key
